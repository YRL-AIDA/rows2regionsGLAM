# AGENTS.md - Инструкции для ИИ-агентов

## Цель
Код экспериментов над модулем для восстановления логической структуры из PDF документа из базовых элементов (слов, строк) с использованием графовой нейронной сети (GNN).

## Технологии
Проект на языке Python с использованием библиотек: PyG - для графовой архитектуры, PageRLib (локальная разработка) - для извлечение элементов из документа. Разработка ведется на локальном устройстве (с debug_data), а тестирование на сервере без агентов со всем набором данных (запуск должен быть в один клик)

## Команды
- Установка (переустановка): python -m pip install .
- Тестирование: python -m unittest tests
